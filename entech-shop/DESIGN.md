# ENTECH Design System

Token ทั้งหมดอยู่ใน `src/app/globals.css` (`@theme`) ให้ใช้ class ของ token เสมอ ห้ามใส่สี hex หรือใช้สี Tailwind ดิบ (slate/green/amber/red) ตรงในคอมโพเนนต์

ทุกคู่สีด้านล่างผ่าน WCAG AA (ข้อความปกติ ≥ 4.5:1) และมีเทสตรวจอัตโนมัติใน `tests/e2e/ux.spec.ts`

## ตัวอักษร: IBM Plex Sans Thai

| ระดับ | ขนาด / น้ำหนัก | สี |
|---|---|---|
| H1 | 30–36px / 700 | navy-900 |
| H2 | 24px / 700 | navy-900 |
| H3 / หัวการ์ด | 18–20px / 700 | ink |
| Body | 16px | ink |
| Small | 14px | ink หรือ muted |
| Caption | 12px (ขั้นต่ำสุด) | muted |
| ราคา | การ์ด 20px / หน้าสินค้า 36px, 700 | navy-700 |

ช่องกรอกบนมือถือต้องใช้ 16px (`input` utility ตั้งไว้แล้ว) เพื่อกัน iOS ซูมหน้าเอง

## ระยะห่างและ radius

- **ระยะห่าง:** สเกลทีละ 4px, section `py-10`/`py-12`, การ์ด `p-5`/`p-6`, ฟอร์ม `gap-4`
- **Radius:**
  - ปุ่มและช่องกรอก 8px (`rounded-lg`)
  - ตัวเลือกที่กดเลือกได้ 12px (`rounded-xl`)
  - การ์ด 16px (`rounded-2xl`)
  - รูปใหญ่และ hero 24px (`rounded-3xl`)
  - badge และช่องค้นหา `rounded-full`

## ปุ่ม (`@utility` ใน globals.css)

- ความสูงขั้นต่ำ 44px (`min-h-11`) และมี focus ring สี cyan-600 เสมอ
- ชนิดปุ่ม:
  - **`btn-primary`:** การกระทำหลัก ใช้ได้ **1 ปุ่มต่อพื้นที่**
  - **`btn-outline`:** การกระทำรอง
  - **`btn-line`:** ช่องทาง LINE
  - **`btn-danger`:** ลบ (ต้องมีการถามยืนยัน)
  - **`btn-cyan`:** ใช้เฉพาะบนพื้นเข้ม
- ปุ่มที่กดไม่ได้ต้องมีข้อความบอกเหตุผลอยู่ใกล้ปุ่ม

## ฟอร์ม

- ใช้คอมโพเนนต์ `Field` (`src/components/field.tsx`) ซึ่งใส่ `aria-invalid` และ `aria-describedby` ให้อัตโนมัติ และแสดง error ใต้ช่อง
- **ตอนส่ง:** ตรวจทุกช่องในรอบเดียว แล้วเลื่อนหน้าและ focus ไปช่องแรกที่ผิด
- **ตอนแก้:** error ของช่องนั้นหายทันทีที่ผู้ใช้แก้
- **ฟอร์มหลังบ้าน:** ใช้ `ActionForm` และ `SubmitButton` ซึ่งมีสถานะ "กำลังบันทึก…" และแสดงผลลัพธ์ใกล้ฟอร์ม ค่าที่กรอกไม่หายเมื่อเกิด error

## สถานะ

- **คำสั่งซื้อ:** ใช้ `StatusBadge` ชุดเดียวกันทั้งหน้าร้านและหลังบ้าน
- **โหลด:** มีแถบ progress ด้านบน (`NavProgress`) และ skeleton ในกล่องสรุป
- **ผิดพลาด:** แสดงข้อความภาษาไทยพร้อมปุ่ม "ลองใหม่"
- **ว่าง:** บอกเหตุผลและให้ทางไปต่ออย่างน้อย 2 ทาง
