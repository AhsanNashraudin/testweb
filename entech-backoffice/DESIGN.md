# ENTECH Back-office: Design System

Token อยู่ใน `src/app/globals.css` (`@theme`) และชิ้นส่วนร่วมอยู่ใน `src/components/bo.tsx`
- ใช้ class ของ token เท่านั้น ห้ามใช้ hex หรือสี Tailwind ดิบ
- ยกเว้นเฉดเทา slate-50/100/200/300/400/500 สำหรับพื้น เส้น และสถานะ disabled
- ชุดสีเดียวกับหน้าร้าน (`../entech-shop/DESIGN.md`) แต่ข้อมูลแน่นกว่า เพราะเป็นเครื่องมือทำงานของพนักงาน

## สี
| Token | ใช้กับ |
|---|---|
| navy-900 `#16304f` | sidebar, H1, H2 |
| navy-700 `#254b7c` | ปุ่มหลัก ลิงก์ เลขเอกสาร แท็บที่เลือก |
| navy-100 / navy-50 | badge info, hover |
| cyan-700 `#0072b1` | avatar/accent ที่มีตัวอักษรขาว |
| cyan-600 | focus ring, progress (ห้ามวางตัวอักษรบน cyan-500/600) |
| ink `#1b2430` | ข้อความหลัก |
| muted `#45556c` | ข้อความรอง (≥ 6.9:1 บน slate-100) |
| success / warning / sale + พื้น `-50` | สถานะ: ปกติ / เตือน / ผิดพลาด-เกินกำหนด |
| line `#05873e` | ปุ่ม LINE (ตรงกับหน้าร้าน) |

**พื้นหลัง:** หน้า slate-100 · การ์ดขาว + border slate-200 · หัวตาราง slate-50

**ความหมายของสีต้องเหมือนกันทุกหน้า:**
- เขียว = เสร็จ/ปกติ
- น้ำเงิน = กำลังทำ
- น้ำตาล (warning) = ใกล้เกณฑ์/รอ เช่น "ต่ำกว่าจุดสั่ง"
- แดง = หมด/เกินกำหนด/ผิดพลาด
- เทา = ยกเลิก/ยังไม่เริ่ม

ห้ามใช้ warning คู่กับ sale ในกราฟเดียวกันโดยไม่มีป้ายกำกับ (กราฟอายุลูกหนี้ใช้ amber-400 แทน)

## ตัวอักษร: IBM Plex Sans Thai
| ระดับ | ขนาด/น้ำหนัก | สี |
|---|---|---|
| H1 หน้ารายการ | `text-2xl md:text-3xl` / 700 | navy-900 |
| H1 หน้ารายละเอียด | `text-2xl` / 700 | navy-900 |
| H2 หัวการ์ด | `text-lg` (ค่าเริ่มต้นใน base) / 700 | navy-900 |
| ตัวเลข KPI | `text-2xl` / 700 | ink |
| Body / ตาราง / ฟอร์ม | `text-sm` | ink |
| Caption | `text-xs` ขั้นต่ำ (ห้ามใช้กับข้อมูลที่ต้องตัดสินใจ) | muted |

- ห้ามใช้ `text-[11px]` หรือเล็กกว่า
- ตัวเลขในตารางเป็น tabular-nums และชิดขวา
- ช่องกรอกบนมือถืออย่างน้อย 16px (กัน iOS ซูม) ส่วนช่องตัวเลขใหญ่ใช้ class `num-big`

## ระยะห่างและความกว้าง
- ใช้สเกลทีละ 4px
- `main`: `p-4 md:p-8` · ระหว่าง section ใช้ `space-y-5` · การ์ดใช้ `p-5`
- เซลล์ตารางมี `padding-inline: .75rem` เป็นค่าเริ่มต้น (กันตัวเลขชิดกัน)
- ความกว้าง:
  - หน้ารายการ: เต็มความกว้าง
  - หน้ารายละเอียด: `max-w-6xl`
  - ฟอร์ม/ตั้งค่า: `max-w-5xl`
  - เอกสารพิมพ์: `max-w-4xl`
  - หน้าโรงงานบนมือถือ: `max-w-md`
- ตารางต้องพอดีในจอ 1366px โดยไม่ต้องเลื่อนแนวนอน ถ้าต้องมีแผงข้าง ให้แผงลงไปอยู่ล่างก่อนถึง `2xl`
- ฟอร์มหลายคอลัมน์ให้แบ่งเป็น `sm:grid-cols-2` ก่อนขยายเต็มที่ `2xl` (ต้องใช้งานได้ที่ 768px ที่มี sidebar)

## มุมโค้ง
- ปุ่มและช่องกรอก 8px (`rounded-lg`)
- แท็บและเมนู 12px (`rounded-xl`)
- การ์ด 16px (`rounded-2xl`)
- badge `rounded-full`

## ปุ่ม (`@utility`)
- ทุกปุ่มสูงอย่างน้อย `min-h-11` (44px) ตัวอักษร 14px/600 มี focus ring cyan-600 และเมื่อกดหดลงเล็กน้อย (`active:scale-[.98]`)
- `btn-primary`: 1 ปุ่มต่อพื้นที่ (หัวหน้า 1 ปุ่ม การ์ดละ 1 ปุ่ม)
- `btn-outline`: การกระทำรอง
- `btn-danger`: ลบ/ยกเลิก ต้องถามยืนยันเสมอ
- disabled: พื้น slate-200 + ตัวอักษร slate-600 (ไม่ใช้ opacity) และต้องมีข้อความเหตุผลใกล้ปุ่ม
- การกระทำหลักของหน้าอยู่ใน `PageHead` และใช้ชื่อเดียวกันทุกหน้า (เช่น "+ ใบเสนอราคาใหม่")
- ปุ่มรับเงินใช้ชื่อเดียวกันทุกที่: "บันทึกรับเงิน"

## ฟอร์ม
- ทุกฟอร์มที่บันทึกข้อมูลใช้ `ActionForm` + `SubmitButton` (ห้ามใช้ `<form action>` เปล่า) เพื่อให้กันกดซ้ำได้ ค่าที่กรอกไม่หาย และแจ้งผลใกล้ฟอร์ม
- ข้อผิดพลาดที่ระบุช่องให้ throw `new BoError(msg, 400, 'ชื่อ input')` แล้วช่องนั้นจะขึ้นกรอบแดง ได้โฟกัส และ `aria-describedby`
- ตัวเลขใช้ `int(v, min, max, ['name', 'ป้าย'])` และ input ต้องมี `min`/`max` ตรงกับฝั่งเซิร์ฟเวอร์
- utility `input` สูง `min-h-11` เท่ากับปุ่ม เส้นขอบ slate-400 (≥ 3:1)

## Badge
- ใช้ `Badge`/`StatusBadge` เท่านั้น (12px/600 + ring) ทุกคู่สีต้องได้ ≥ 4.5:1

## สถานะหน้าจอ
- **ระหว่างโหลด:** แถบ `NavProgress` + ป้าย "กำลังโหลด…" (ไม่ใช้ `loading.tsx` เพราะจะล้างทั้งหน้าและทำให้หน้า 404 ตอบ 200)
- **ไม่มีข้อมูล:**
  - ถ้ามีตัวกรองอยู่ ให้บอก "ไม่พบตามตัวกรอง" พร้อมลิงก์ล้างตัวกรอง
  - ถ้ายังไม่มีข้อมูลเลย ให้บอกขั้นต่อไปที่ต้องทำ
- **ผิดพลาด:** ข้อความไทยพร้อมรหัสอ้างอิง ห้ามแสดง SQL หรือข้อความภายในให้ผู้ใช้เห็น

## ตรวจก่อน merge
- contrast ข้อความ ≥ 4.5:1 · เส้นขอบ/ไอคอนที่ต้องมองเห็น ≥ 3:1
- ถ่ายภาพที่ 1366, 768 และ 390px ต้องไม่มีปุ่มถูกตัดและไม่มีการเลื่อนแนวนอนทั้งหน้า
- เป้าแตะสำคัญ ≥ 40px (ปุ่ม 44px)
