## B. เตรียมก่อนวันย้าย (ทำล่วงหน้าได้)
- [ ] B1 ซื้อ/ต่ออายุแพ็กเกจ Hostatom ที่ **เปิด Node.js ได้** (ถาม Node 20/22 และ RAM) — ถ้าไม่ได้ใช้ Cloud VPS
- [ ] B2 ขอสิทธิ์จัดการ DNS ของโดเมน `entechproducts.co.th` (ล็อกอินผู้รับจดโดเมน) · ถ้ายังมีโดเมนเก่า `entech-products.com` ให้ขอสิทธิ์ด้วย (ตั้ง 301 มาโดเมนใหม่)
- [ ] B3 ตรวจว่าอีเมล @entechproducts.co.th ใช้อยู่ไหม → จด **MX record** เดิมไว้ (กันอีเมลดับตอนย้าย)
- [ ] B4 ลด TTL ของ DNS เป็น 300 วินาที ล่วงหน้า 1 วัน (ย้ายแล้วเห็นผลเร็ว)
- [ ] B5 สร้าง Token ใหม่ใน Turso (ใช้ดึงข้อมูลครั้งเดียว) — **ไม่ส่งในแชท**
- [ ] B6 สุ่ม `SESSION_SECRET` (PowerShell: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`)
- [ ] B7 ลบคำสั่งซื้อ/ใบเสนอราคาทดสอบในหลังบ้าน (ถ้ามี) หรือเปลี่ยนสถานะเป็นยกเลิก

## C. วันย้าย (ใช้เวลาประมาณ 1–2 ชม.)
- [ ] C1 ดึงข้อมูลจาก Turso → `entech.db` (DEPLOY ข้อ 1.5) · ตรวจจำนวนแถวที่สคริปต์แสดง
- [ ] C2 Plesk: แตก `entech-hostatom.zip` ใน `httpdocs` · สร้าง `entech-data/` · อัป `entech.db` (DEPLOY ข้อ 2)
- [ ] C3 Node.js: Startup `app.js` · Document Root `/httpdocs/public` · Node 22 (DEPLOY ข้อ 3)
- [ ] C4 Environment Variables (ค่าครบด้านล่าง) → Enable → Restart
- [ ] C5 ทดสอบผ่านโดเมนชั่วคราว/IP ของ Hostatom ก่อนย้าย DNS (ถ้า Hostatom ให้ preview URL)
- [ ] C6 ย้าย DNS → Hostatom (ใส่ MX เดิมกลับด้วย) → ออก SSL Let's Encrypt (รวม www) → บังคับ HTTPS → Preferred domain = www.entechproducts.co.th

**Environment Variables ที่ต้องใส่ใน Plesk**
```
NODE_ENV=production
SITE_URL=https://www.entechproducts.co.th
DATABASE_URL=file:../entech-data/entech.db
SESSION_SECRET=(ค่าที่สุ่มใน B6)
STOCK_API_KEY=(เว้นว่างไว้ก่อน — ใส่เมื่อเชื่อมระบบสต็อก ดู STOCK-API.md)
LINE_CHANNEL_TOKEN=(จาก LINE Developers — แจ้งเตือนทีมขาย)
LINE_CHANNEL_SECRET=(จาก LINE Developers)
CRON_KEY=(สุ่มแบบ B6)
```

## D. ตรวจหลังเปิด (วันแรก)
- [ ] D0 **เปลี่ยนรหัสผ่านแอดมินทันที**: หลังบ้าน → ข้อมูลร้าน & ติดต่อ → เปลี่ยนรหัสผ่าน (≥ 12 ตัว)
- [ ] D1 `https://www.entechproducts.co.th` เปิดได้ มีกุญแจ SSL · `http://` และ `www.` เด้งมาที่หลัก
- [ ] D2 หน้าแรก สินค้า หมวด บทความ CSR เกี่ยวกับเรา ติดต่อ — ครบ ไม่มีรูปแตก (เช็กบนมือถือด้วย)
- [ ] D3 สั่งซื้อทดสอบ 1 รายการ (รับเองที่โรงงาน) → QR PromptPay ถูกเลข/ยอด → ยกเลิกในหลังบ้าน (สต็อกคืน)
- [ ] D4 ส่งฟอร์มขอใบเสนอราคา → เข้าหลังบ้าน
- [ ] D5 ลิงก์เว็บเดิม เช่น `/16507193/...` เด้งไปหน้าสินค้าใหม่ (301)
- [ ] D6 `/robots.txt` และ `/sitemap.xml` ชี้โดเมนจริง
- [ ] D7 หลังบ้าน → สำรองข้อมูล → "สำรองอัตโนมัติ ล่าสุด" มีวันเวลา · กด "สำรองตอนนี้" ได้ · ดาวน์โหลดชุดสำรองครบได้
- [ ] D8 Plesk Backup Manager ตั้ง Scheduled backup รายวันแล้ว
- [ ] D9 อีเมลบริษัทรับ-ส่งได้ปกติ
- [ ] D10 หลังบ้าน → ทีมขาย & แจ้งเตือน: ใส่รายชื่อเซลล์/หัวหน้า/ผู้บริหาร + LINE ID → "ส่งข้อความทดสอบ" ได้ · ส่งฟอร์มทดสอบ 1 ครั้ง → เซลล์ได้ LINE
- [ ] D11 Plesk Scheduled Task เรียก `/api/cron?key=…` ทุก 15 นาที (DEPLOY ข้อ 6.6)
