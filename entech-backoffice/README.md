# ENTECH Back-office (หลังบ้าน)

ระบบหลังบ้าน **แยกจากเว็บไซต์** (`../entech-shop`) — คนละแอป คนละฐานข้อมูล คนละ deploy · คุยกับเว็บผ่าน **Stock API v1** เท่านั้น (โค้ดเว็บไม่ต้องแก้)

| โมดูล | หน้า |
|---|---|
| แดชบอร์ด · ยอดขาย ออเดอร์ตามขั้นตอน งานเกินกำหนด สต็อกต่ำ | `/` |
| ติดตามออเดอร์ · อยู่ขั้นไหน ค้างที่ใคร เกิน SLA หรือยัง | `/tracking` |
| คำสั่งซื้อ (เว็บ + เซลล์) · ส่งต่อขั้นตอน ยืนยันรับเงิน เลขพัสดุ ประวัติ | `/orders` |
| ใบเสนอราคา → เปิดออเดอร์ (ตัดสต็อก + เปิดใบสั่งผลิตส่วนที่ขาดอัตโนมัติ) · พิมพ์ PDF | `/quotes` |
| คลังสินค้า · ถังสำเร็จรูป/วัตถุดิบ จอง/พร้อมขาย จุดสั่ง ราคา SKU ใหม่ | `/inventory` |
| โรงงาน · บอร์ดใบสั่งผลิต สูตร BOM ทดสอบรั่วซึม · หน้ามือถือช่าง `/production/m` | `/production` |
| บัญชี & e-Tax · ใบกำกับภาษี/ใบเสร็จ ลูกหนี้ อายุหนี้ CSV ให้สำนักงานบัญชี/Bplus | `/accounting` |
| เชื่อมเว็บไซต์ & หัวเอกสาร | `/settings` |

ขั้นตอนออเดอร์: รับออเดอร์ → อนุมัติ (ส่วนลด > 5%) → ผลิต → แพ็ค/ส่ง → ออกบิล → รับเงิน → จบงาน (กฎทั้งหมดใน `src/lib/backoffice-rules.ts`)

## การเชื่อมกับเว็บ (`src/lib/sync.ts`)
ทุก 5 นาที (Vercel Cron → `/api/cron/sync`) หรือกด "ซิงค์ตอนนี้":
1. `GET /orders?cursor=` ดึงออเดอร์เว็บใหม่ → ตัดสต็อก · รับ "ชำระแล้ว/ยกเลิก" ที่แอดมินเว็บกด
2. `PATCH /orders/{code}` ส่งสถานะ + เลขพัสดุที่หลังบ้านเปลี่ยนกลับให้ลูกค้าเห็น
3. `PUT /items` ส่งสต็อก/ราคาที่เปลี่ยน (ทำหลังข้อ 1 เสมอ)

ครั้งแรกนำเข้า SKU ทั้งหมดจาก `GET /items` อัตโนมัติ · หลังจากนั้นหลังบ้านเป็นเจ้าของ SKU/ราคา/สต็อก ส่วนเว็บเป็นเจ้าของรูป คำอธิบาย SEO

## รันในเครื่อง
```bash
cp .env.example .env          # ใส่ WEB_API_URL=http://localhost:3000/api/v1 และ WEB_API_KEY = STOCK_API_KEY ของเว็บ
npm install && npm run db:push && npm run db:seed
npm run dev                   # http://localhost:3001  (admin@entech.local / Entech@2026 — dev เท่านั้น)
npm run db:demo               # (ไม่บังคับ) ข้อมูลตัวอย่าง ต้องเปิดเว็บไว้เพื่อนำเข้าสินค้า
```
ทดสอบ: `npm test` (กฎธุรกิจ) · `npm run test:e2e` (วงจรเต็ม ใบเสนอราคา→ผลิต→บิล→รับเงิน)

## Deploy (Vercel project ใหม่ แยกจากเว็บ)
- Root Directory: `entech-backoffice` · Build Command: `npm run vercel-build`
- สร้าง Turso DB ใหม่ (ไม่ใช้ร่วมกับเว็บ) → `DATABASE_URL`, `DATABASE_AUTH_TOKEN`
- `SESSION_SECRET` (≥ 32 ตัว), `ADMIN_EMAIL`, `ADMIN_PASSWORD`
- `WEB_API_URL=https://<โดเมนเว็บ>/api/v1`, `WEB_API_KEY` = ค่า `STOCK_API_KEY` ที่ตั้งในโปรเจกต์เว็บ
- `CRON_SECRET` (Vercel ส่งให้ cron อัตโนมัติ) · Cron ทุก 5 นาทีต้องใช้แพลน Pro (Hobby รันได้วันละครั้ง — กดซิงค์มือได้เสมอ)

## ⚠ ต้องยืนยันกับลูกค้าก่อนใช้จริง
- สูตรการผลิต (BOM) ประมาณจากน้ำหนัก/ความจุถัง → ให้โรงงานยืนยันอัตราจริง
- e-Tax ยังบันทึกสถานะด้วยมือ จนกว่าจะเลือกผู้ให้บริการ (หรือส่งผ่าน Bplus)
- ผู้ใช้ตอนนี้มีบทบาทเดียว (ทุกคนทำได้ทุกอย่าง) — ถ้าต้องแยกสิทธิ์ เซลล์/บัญชี/โรงงาน เพิ่มได้ภายหลัง

Skills ที่ใช้พัฒนา (vendored ใน `.claude/skills`): ponytail, agent-skills, graphify
